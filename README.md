# Music Request System LITE
A lighter version of the MRS software designed for older systems and PHP versions

The Music Request System was officially conceived in 2015, and released to the public in 2017.

Recent releases of the software have (or will) dropped support for PHP versions lower than 5.5.0, and newer releases to come soon will drop support for releases <= 7.0.0.
Of course, PHP7 is quite old; even Debian 10, which is now into ELTS support, shipped with PHP 7.3 by default.

But, for those that want to run the MRS on old hardware that may not necessarily support newer releases of operating systems, or for those that simply want a stripped-down request system, this software fills that gap.

More information is available here: http://firealarms.mooo.com/mrs-lite
Downloads are available either via the releases tab, or at http://firealarms.mooo.com/mrs-lite#downloads
Setup information is available at http://firealarms.mooo.com/mrs-lite#setup
